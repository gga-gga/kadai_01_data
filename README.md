# MMA Fighter Data Analysis
## データが語る「勝利の法則」― UFC選手スタッツの収集と分析

---

## 概要

UFC（Ultimate Fighting Championship）の全登録選手のスタッツ（統計数値）を
スクレイピングで収集し、**高勝率選手に共通する特徴をデータで定量化する**プロジェクトです。

「強い選手はなぜ強いのか」という問いに、直感ではなくデータで答えることを目指します。
